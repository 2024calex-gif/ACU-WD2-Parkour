# T25 dive13: slow root during the roll and the get-up (S18 window, k 1.00 / 1.00)

Generated by `v2/pipeline/dive13.py` (`dive13.py baseline`, then `dive13.py variant`). Written only under `out\dive13`. The bake is dive12's run_case (dive11 chain, dive9 solver, dive8 timing) with the SlideOver and Exit roots installed on the context. Nothing in dive9 to dive12 is changed.

## 1. Result

The root patch does what it was written to do: identical to the original before 1.20 s, C1 at 1.20 s, speed >= 0, z = 0 after it, and the floor rule still holds (0.263 cm). The skate targets are NOT met. Over the played window the skate p95 is 5.90 m/s (target 0.5) and the max is 8.63 m/s (target 1.0). Two causes, both visible in the numbers below.

* SlideOver: the bake puts the Reference on the WD2 pelvis path, so the root change is absorbed by the Reference and the body's world motion does not change (roll skate identical). The root alone cannot change the roll slide.
* Exit: the root does set the body's motion. It now runs at the natural speed (2.91 m/s at W, rising to Nav_Run's 4.54 m/s), so the Exit window and the get-up improve (section 3), but the lowest bone also moves with the stand-up rotation, so it still reaches 5 to 6 m/s there.

Section 6 gives the reason the targets cannot be met with the brief's constraints.

## 6. Why the targets are not met, and what would be needed

* The root alone does not move the SlideOver body. The bake sets the Reference so that the pelvis lands on the WD2 path. A slower root moves the Reference by the same amount, so the world motion is unchanged (roll p95 3.42 vs 3.42 m/s). The roll slide is the WD2 pelvis path itself: 1 to 3 m/s while the body is still low.
* In the Exit the root does set the body motion, so the slow Exit root helps: the Exit window p95 goes from 7.29 to 6.00 m/s, and the get-up p95 from 6.97 to 5.53 m/s. The get-up max rises a little (8.37 to 8.63 m/s, left hand). The lowest bone moves faster than the root there (root 2.9 to 4.5 m/s), so the rotation of the stand-up and the Reference carried from W add the rest; I did not separate those two in this run.
* The world pelvis dv metric (dive9 item, already failing) gets worse, 4.55 to 5.29 m/s per frame: the change of the Exit root at W adds a speed step to the pelvis. It is reported, not hidden.
* p95 0.5 and max 1.0 need the body to stop moving forward while the lowest bone is within 12 cm (the WD2 pelvis is at 1 to 3 m/s there). That changes the body path, not the root, and moves the Reference away from the WD2 path and the landing point. It is a decision for the user, so it is not made here.
* Nothing was run in game (rule). The skate numbers are the offline model; the in-game check is still to do.
